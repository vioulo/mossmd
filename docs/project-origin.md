# 项目起源

MossMD 最初是为了给个人博客系统集成一款 Markdown 编辑器。尝试过 Milkdown 等方案后，现有编辑器在接近 Obsidian 的 Live Preview 书写体验、交互流畅度和自定义能力上仍有不足，因此开始构建一个更贴近实际使用习惯的编辑器。

项目早期参考了 [atomic-editor](https://github.com/kenforthewin/atomic-editor)，MossMD 的早期实现可以看作基于它的 fork。之后项目逐步转向独立的 CodeMirror 6 架构，在 AI 协作和持续实践中加入图片块、文件块、表格、Wiki 链接、Callout、上传、图标协议等功能，以满足博客系统和知识库场景中的具体需求。
